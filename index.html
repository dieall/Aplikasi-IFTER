Problem Definition & Relevance

Health Informatics Challenge

Dengan meningkatnya penggunaan aplikasi kesehatan seluler di Indonesia, muncul tantangan penting dalam memastikan kualitas, keamanan privasi, dan literasi pengguna terhadap aplikasi-aplikasi tersebut.

Masalah yang Dihadapi:

  • Kualitas Aplikasi: Tidak semua aplikasi kesehatan memiliki standar kualitas yang sama, baik dari segi fitur, akurasi informasi, maupun user experience.
  • Privasi & Keamanan Data: Banyak aplikasi kesehatan mengumpulkan data sensitif pengguna tanpa transparansi yang jelas tentang penggunaan dan perlindungan data tersebut.
  • Literasi Pengguna: Pengguna seringkali tidak memahami informasi kesehatan yang disajikan atau tidak menyadari implikasi privasi dari penggunaan aplikasi.
  • Kurangnya Evaluasi Komprehensif: Tidak ada sistem evaluasi terpusat yang membantu konsumen memilih aplikasi kesehatan yang tepat sesuai kebutuhan mereka.

Relevansi dengan Health Informatics:

Consumer Health Informatics

Membantu konsumen membuat keputusan informasi kesehatan yang lebih baik melalui evaluasi aplikasi kesehatan.

Health Information Privacy

Meningkatkan kesadaran tentang pentingnya privasi data kesehatan dan transparansi dalam penggunaan data.

Health Literacy

Meningkatkan literasi kesehatan digital pengguna melalui evaluasi dan rekomendasi aplikasi yang informatif.

Quality Assessment

Menyediakan framework evaluasi yang sistematis untuk mengukur kualitas aplikasi kesehatan seluler.

Tujuan Sistem:

  1. Menyediakan evaluasi komprehensif aplikasi kesehatan berdasarkan kriteria objektif
  2. Meningkatkan transparansi tentang privasi dan keamanan data aplikasi kesehatan
  3. Membantu konsumen membuat keputusan informasi yang lebih baik
  4. Mendorong pengembang aplikasi untuk meningkatkan kualitas dan privasi

Ethical & Governance Reflection

Privacy & Security Considerations

1. Data Privacy

Prinsip: Sistem ini tidak mengumpulkan data pribadi pengguna. Semua data evaluasi adalah data publik tentang aplikasi kesehatan, bukan data pengguna.

  • Tidak ada tracking atau analytics yang mengumpulkan data pribadi
  • Tidak ada cookies yang menyimpan informasi sensitif
  • LocalStorage hanya digunakan untuk preferensi UI (dark mode)

2. Security Measures

  • Input Validation: Semua input dari user divalidasi untuk mencegah injection attacks
  • CORS Policy: CORS diaktifkan dengan kontrol yang tepat
  • Error Handling: Error messages tidak mengekspos informasi sensitif sistem
  • HTTPS: Direkomendasikan menggunakan HTTPS di production

3. Ethical Considerations

Transparansi Evaluasi:
  • Kriteria evaluasi dijelaskan dengan jelas
  • Skor dan penilaian didasarkan pada metrik objektif
  • Rekomendasi perbaikan bersifat konstruktif
Fairness:
  • Semua aplikasi dievaluasi dengan kriteria yang sama
  • Tidak ada bias terhadap aplikasi tertentu
  • Evaluasi didasarkan pada data faktual

4. Governance Framework

Data Governance:
  • Data evaluasi dikelola dengan struktur yang jelas
  • Update data dapat dilakukan dengan mudah
  • Version control untuk tracking perubahan
Quality Assurance:
  • Validasi data sebelum ditampilkan
  • Error handling yang komprehensif
  • Testing untuk memastikan akurasi

5. Recommendations for Improvement

  • Implementasi authentication jika diperlukan untuk fitur admin
  • Penambahan audit log untuk tracking perubahan data
  • Regular security updates dan patches
  • Compliance dengan regulasi data privacy (GDPR, PDPA)
  • User consent mechanism jika akan mengumpulkan data
